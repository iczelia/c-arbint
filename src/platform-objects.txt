# Platform-specific object files for arbint
#
# Format: name condition [cflags]
#   name      - base name without .c extension
#   condition - automake conditional (ARBINT_BUILD_* or ARBINT_HAS_*)
#   cflags    - optional CFLAGS variable for special compiler flags
#
# To add a new platform-specific file:
#   1. Add a line here
#   2. Add detection in configure.ac (AM_CONDITIONAL + optional AC_SUBST for flags)
#   3. Add the .c file to EXTRA_DIST in src/Makefile.am
#   4. Run autoreconf -fi
